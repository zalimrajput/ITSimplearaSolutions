# Machine Learning Projects

This repository contains my machine learning projects, developed to solve real-world problems using data analysis, machine learning algorithms, and predictive modeling.

## Projects

### 1. AgriPak Farms – Low-Yield Risk Prediction

**Objective:** Predict whether an agricultural field is at risk of low yield before harvest.

- **Dataset:** 50,000 agricultural records
- **Task:** Week 1 – Data Cleaning, EDA, and Baseline Model
- **Model:** Logistic Regression
- **Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Evaluation:** Accuracy, Precision, Recall, and F1-score

**Baseline Results:**
- Accuracy: 91.87%
- Precision: 88.84%
- Recall: 87.80%
- F1-score: 88.32%
